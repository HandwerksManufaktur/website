Vorbereitung: eure neue Website geht online

Eure neue Website bekommt ein eigenes Konto bei GitHub. Dort liegt sie, sie gehört euch, und es fallen keine monatlichen Hosting-Kosten an. Wenn diese Punkte vorab erledigt sind, ist der gemeinsame Termin in wenigen Minuten durch.

⏱ Dauert ca. 10 Minuten
1

Google Authenticator aufs Handy laden

Die App erzeugt den Sicherheitscode, den GitHub beim Einloggen zusätzlich abfragt („Zwei-Faktor“). GitHub schreibt das für alle Konten vor. Wenn ihr die App schon habt (zum Beispiel von Facebook), einfach diesen Punkt überspringen.

Google AuthenticatorSo sieht die App aus: bunter Stern, Anbieter „Google LLC“. Die App ist kostenlos.

👉 Tippt einfach auf euren Store, der Link führt direkt zur richtigen App:

📱 iPhone, zum App Store 🤖 Android, zum Play Store

Dort auf „Laden“ bzw. „Installieren“ tippen, die App einmal öffnen und wieder zur Seite legen.

2

GitHub-Konto anlegen

Am besten am PC oder Laptop. Das Konto läuft auf euren Betrieb und eure E-Mail-Adresse.

→ github.com/signup öffnen
  • E-Mail-Adresse eintragen: die Adresse, die ihr täglich lest (dorthin kommen die Bestätigungscodes)
  • Passwort ausdenken: mindestens 15 Zeichen, oder mindestens 8 Zeichen mit einer Zahl und einem Kleinbuchstaben. Gleich auf den Zettel unten schreiben.
  • Benutzername: euer Firmenname ohne Leerzeichen, zum Beispiel schreinerei-mueller. Ist er vergeben, hängt den Ort an.
  • Die Frage nach Neuigkeiten per E-Mail könnt ihr verneinen → „Continue“ / „Weiter“
  • GitHub zeigt ein kurzes Rätsel (Bilder auswählen), das ist normal → lösen
  • In euer Postfach schauen: GitHub schickt einen 8-stelligen Code → auf der Seite eintippen
  • Fragen zu Team-Größe oder Interessen einfach überspringen („Skip“). Wenn nach einem Tarif gefragt wird: „Free“, das kostenlose Konto reicht völlig.
3

Zwei-Faktor bei GitHub einschalten

Eingeloggt bei GitHub, am PC:

  • Oben rechts auf euer Profilbild klicken → „Settings“
  • Links „Password and authentication“ → „Enable two-factor authentication“
  • GitHub zeigt einen QR-Code. Darunter steht klein „setup key“: anklicken, den Schlüssel (lange Buchstabenreihe) auf den Zettel schreiben
  • In der Google-Authenticator-App auf „+“ → „QR-Code scannen“ → Handykamera auf den QR-Code am Bildschirm halten
  • Die App zeigt jetzt einen 6-stelligen Code → bei GitHub eintippen
  • GitHub zeigt Wiederherstellungscodes („recovery codes“) → „Download“ und die Datei aufheben, oder ausdrucken. Damit kommt ihr immer wieder rein, falls das Handy mal weg ist.
  • Zum Schluss auf „Done“ klicken → fertig ✅
Warum der Schlüssel auf den Zettel: Wir nehmen ihn im Termin zusätzlich in unseren verschlüsselten Passwort-Tresor. So können wir Änderungen an eurer Seite einspielen, ohne euch jedes Mal nach einem Code vom Handy zu fragen. Euer Zugang bleibt trotzdem voll bei euch.

Hängt ihr hier irgendwo: kein Problem, den Schritt machen wir im Termin zusammen fertig.

4

Alles auf einen Zettel schreiben

Diese vier Angaben braucht ihr im Termin. Am besten ausdrucken und ausfüllen, oder abschreiben:

E-Mail-Adresse
Benutzername
Passwort
Setup key (Zwei-Faktor)
Bitte nicht per E-Mail oder WhatsApp schicken. Den Zettel einfach im Termin neben euch legen, wir übernehmen die Angaben direkt.
5

Zugang zu eurer Domain bereitlegen

Damit eure Adresse (zum Beispiel www.euer-betrieb.de) auf die neue Seite zeigt, stellen wir bei eurem Domain-Anbieter einen Eintrag um. Das ist meist dort, wo ihr die Domain bezahlt: zum Beispiel IONOS, Strato, Raidboxes oder All-Inkl.

Sucht die Zugangsdaten raus und probiert vorher einmal aus, ob der Login klappt. Passwort vergessen? Am besten jetzt schon zurücksetzen, nicht erst im Termin.

Keine Sorge um eure E-Mails: Wir ändern nur den Eintrag für die Website. Eure E-Mail-Adressen laufen unverändert weiter.
6

Zugang zur alten WebsiteOptional

Falls vorhanden: die Zugangsdaten zur bisherigen Website (zum Beispiel WordPress) oder den Kontakt zu eurem bisherigen Webdesigner. Damit sichern wir die alte Seite und leiten alte Links auf die neuen Seiten um, damit bei Google nichts verloren geht.

7

Im Termin: PC an, E-Mail-Postfach offen

Wir telefonieren ca. 10 Minuten. Setzt euch dafür an den PC, lasst euer E-Mail-Postfach offen (GitHub schickt eventuell einen Code) und habt das Handy mit der Authenticator-App und den Zettel neben euch. Den Rest machen wir.
